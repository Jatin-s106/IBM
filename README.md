# CareerCompass AI - Skill-based Career Recommender, Resume Builder & Interview Coach
IBM SkillsBuild Masterclass 5 | SDG 8: Decent Work & Economic Growth | TYIT project
Author: JATIN MAHAVIR SHARMA | Internship ID: IBMUEML004570

## Run
```
pip install -r requirements.txt
python app.py          # open http://127.0.0.1:5000
python -m unittest discover -s tests -v    # 20 tests
```

## Features
Career Matcher (42 skills, 15 careers, city tier + remote) | Career Explorer | Skill-gap Roadmap with progress tracking |
Resume Builder (7-point score, PDF) | Mock Interview (HR + technical) | Login & Dashboard.

## Files
app.py (routes, DB, PDF) | engine.py (logic) | data.py (knowledge base) | templates/ | static/ | tests/ | docs/
Salaries are indicative entry-level figures and vary by company and city.
